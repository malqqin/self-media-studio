# 知序 · 自媒体创作平台

本地运行的文章、视频和图片创作工作台。以任务组织创作：每个任务独立配置内容方向、参考资料、模型和执行时间，每次运行保留一份作品和配置快照。

## 启动

Windows 安装 Python 3.11+、Node.js 后运行：

```powershell
.\start.ps1
```

打开 http://127.0.0.1:8765。首次启动安装依赖并构建前端。开发模式使用 `./start.ps1 -Dev`；修改前端后运行 `npm run build`，修改后端后重启服务。可用 `./start.ps1 -NoOpen` 只启动服务。

数据、密钥、上传素材和生成作品保存在 `data/`，不进入 Git。升级前可用 SQLite backup 接口备份数据库。旧文章、视频和已启用的每日计划会迁入任务列表，保留原作品；迁移不会重新生成内容。

## 从任务开始

1. **首页**查看最近创建的任务，**任务列表**按文章、视频、图片筛选或搜索。
2. 点击**新建任务**，填写名称并选择类型，进入对应工作台。
3. 在**任务配置**中填写方向、创作方式、模型和资料来源。
4. **创建手动草稿**无需配置模型，可直接编辑；**AI 辅助创作**使用选定模型生成内容。
5. 在**作品与执行记录**查看进度、编辑作品、检查来源并导出。每次创作建立新作品，不覆盖以前的作品。

任务详情使用紧凑顶部，隐藏全局导航，点击“任务列表”返回。操作成功与失败通过顶部居中的浮动提示显示；错误保留到手动关闭或对应任务恢复执行，后台轮询不会重复弹出同一次错误。重新生成、换角度、离开未保存编辑使用站内确认弹窗，支持取消、Escape 和键盘操作；关闭或刷新整个浏览器页面时的未保存提醒仍由浏览器处理。

任务可归档、恢复；归档后暂停自动执行。正在执行的任务不能归档。同一个任务同时只允许一份作品处于生成状态；多个任务可独立排队。配置保存和作品编辑都检查版本，避免不同页面互相覆盖。离开尚未保存的编辑会提示。

### 公众号文章

每个任务独立保存公众号名称、定位、读者、风格、目标字数（400–4000 字）、文章形式和偏好。

文章形式支持 48 种，按知识解读、热点观点、实用方法、测评对比、故事人文、旅行生活、阅读成长、品牌商业 8 类分组，选择后显示用途说明。例如旅行攻略、景点介绍、访谈、产品测评、案例分析、书评、品牌故事、项目复盘。形式影响自动选题、角度、大纲、正文和局部改写的组织方式，排版外观仍由模板控制；原有解读、教程、清单、随笔保持兼容，已有作品保留创作时的形式。访谈与测评须依据真实记录，无记录时采用资料问答或公开资料分析，不冒充采访或亲测。

- **从零构思**：依据定位和可选的具体主题、个人笔记提出写作角度。
- **参考文章创作**：联网查找、采集指定链接或选择已有资料。可选择参考事实与观点、文章结构或表达风格；结构和文风参考要求完整正文，不用搜索摘要推测原文写法。独立创作，不逐句替换原文。
- 手动 AI 流程：生成角度 → 选择角度 → 编辑/确认大纲 → 撰写正文 → 检查与修改。步骤条可以返回已完成阶段，第二步提供“上一步：写作角度”。仅返回查看不改变作品；改选角度、保存新大纲或重新生成正文前会确认，原内容保留在版本记录中。未保存的修改需先保存或撤销。
- **围绕方向持续创作**：填写长期范围，例如“山西旅游景点，每篇介绍一个地方”。每次先规划具体对象与文章要求，参考近 7–90 天（默认 30 天）的已成稿主题避开重复，再收集资料、选角度、生成大纲和正文。具体主题保存在执行记录，重试沿用同一主题；近似同名主题重选一次仍重复时停止。语义上的近似选题仍需人工判断。
- **写一个具体话题**：直接使用填写的话题，不额外换题。旧任务保持此模式，切换持续创作后才启用主题规划。两种模式均可手动辅助或定时自动执行；自动流程继续生成大纲、正文并检查。
- 编辑标题、摘要、正文、封面和章节图片，手机阅读预览、局部改写、引用校验、版本记录与恢复。
- **流式生成**：写作角度、大纲、正文、局部调整与检查通过 SSE 实时展示模型已返回的文字，支持 Chat Completions 和 Responses 协议。可关闭“跟随输出”停留阅读，页面断线会重连，后台任务继续执行；不展示推理过程或原始 JSON。兼容接口若一次性返回 JSON 则完成后显示，不伪造逐字输出。只有完整且通过结构校验的结果进入作品，临时输出不会覆盖保存稿。
- **编辑与预览联动**：聚焦主标题、摘要、开头、章节标题、章节正文或结尾，右侧预览自动滚动到对应区域并高亮，不影响复制或导出样式。
- **提示词局部调整**：每个文字区域可输入最多 2000 字的调整要求，正文支持整节或单个自然段；只替换指定区域，其余标题、文字、配图和排版保留。未保存修改在同一事务中先保存为历史版本，再开始调整；失败保留该版本。完成后自动重新检查，可从版本记录撤销。原有缩短、补充解释、调整为口语和重新组织表达按钮继续可用。
- **文章排版模板**：内置 18 套模板，按自然纸感、生活灵感、杂志专栏、清爽实用分类，支持关键词搜索。保留原有六套；新增奶油纸笺、鼠尾草花园、手绘日记、独立杂志、复古报刊、水墨留白、玫瑰来信、海盐蓝调、咖啡札记、奶黄便签、山野明信片、午夜电台。任务配置中可查看完整示例，所选模板用于后续手动草稿和自动生成；已有文章在编辑区单独切换，即时预览，保存后生效。切换不改写正文、不调用模型；历史恢复同时恢复模板。预览、复制排版、HTML / ZIP 导出及公众号草稿共用 `shared/article-templates.json`，Markdown 保留纯内容。六款模板包含平台原创手绘装饰：独立 HTML 内嵌、ZIP 附图片，自动保存公众号草稿时随正文图片上传；手动复制排版时需从图文包另行上传图片。纸张纹理由内联 CSS 绘制，微信可能简化纹理效果，底色与正文仍可阅读。宋体使用设备可用字体，无需加载外部字体。
- 导出 HTML、Markdown 或含图片、文案与来源的 ZIP；可复制排版文字到公众号编辑器。粘贴后图片需另行上传。
- **轻盈动效模板**：在原有 18 套基础上新增林间微风、海岸潮汐、星轨来信、萤火夜读、雨窗随笔、花瓣信笺，共 24 套。原创 SVG/CSS 动效仅作用于开场装饰，编辑预览可暂停并遵循系统“减少动态效果”；模板缩略图保持静态。独立 HTML 使用 SVG 并提供静态 PNG 回退；图文 ZIP 同时包含 `article.html`、使用 GIF 的 `wechat.html` 以及 SVG/GIF/PNG 文件。扫码接入的草稿上传保留 GIF；API 接入通过支持 GIF 的永久图片素材接口上传并使用其微信图片 URL（`uploadimg` 官方仅支持 JPG/PNG），不会转换为静态 JPEG。微信端实际播放需在草稿预览核对。素材均为本地原创，无模型调用；运行 `scripts/render-article-motion.py` 可重新生成 GIF/PNG，`scripts/preview-article-motion.py` 生成 `/template-previews/motion.html` 总览。

文章按阶段保存，失败保留已生成内容，可以从失败步骤继续。模型达到输出限制时显示明确错误，正文生成预算为 16000 tokens；服务商模型限制仍可能导致截断。检查指出问题但不保证事实正确、原创性或流量。

正文交付完整文章，具体创作要求优先于账号风格，不把景点介绍改成采访方案。选题和大纲优先选择凭现有信息能完成的内容；未知票价、开放时间、采访原话等直接省略，资料缺口留在独立编辑区。正文检查识别明显的写作指令、占位符和采写计划，出现时最多追加一次模型修正请求（会计入模型用量），仍不合格则停止并保留大纲与历史版本。完整性检查还会把用户主题和账号定位交给模型核对，并清理与导语、结语完全重复的正文段落。

任务首页、列表卡片和详情页均可删除任务。删除会移入任务列表的“回收站”，停止定时执行，保留已保存作品、资料关联和执行记录；不会删除素材库或微信端已保存/已发布的文章。正在采集、生成或发布时禁止删除，过期页面提交也会校验版本。回收站恢复后放入“已归档”，打开任务并点击“恢复任务”后才重新启用计划。

### 视频

当前支持固定 **10 秒、9:16、无配音** 的短片，1–2 句短标题贯穿全片，1–5 个图片/视频画面。

- 配置主题、画面与文案风格、720p / 1080p，以及可选的上传素材。
- 参考创作读取来源正文并匹配相关图片；原创创作使用个人笔记/内容依据和上传素材。
- 手动编辑标题、画面顺序、素材及视频截取起点，保存后重新合成。
- 自动事实复核、FFmpeg 合成和技术质检后人工审核，审核通过再下载成片包。
- 目前没有配音、长视频或文生视频模型接口；素材不足时提示补充，不伪造成片。

### 图片

支持单张海报与 1–6 页图文卡片。AI 生成文案，系统本地排版为 PNG，也可以从手动草稿开始。

- 3:4 竖版（1080×1440）、1:1 方形（1080×1080）、16:9 横版（1440×810）。
- 浅绿、米色、深蓝三种配色，可选择上传图片作为配图。
- 每页编辑标题、正文和补充说明，保存后生成新版本。
- 下载单张 PNG 或全套图片、文案、配置和来源 ZIP。
- 文字太多时提示缩短或换尺寸，不静默裁掉内容。当前是图文排版，不是扩散模型绘图。

## 自动执行

每个任务可切换手动或自动，独立选择执行时间及星期，采用**北京时间**。保存自动配置即启用；手动模式关闭该任务的定时计划。可立即自动执行一次试跑。

定时器约每 30 秒检查一次，需要本地服务和电脑持续运行。时间已过会补执行当天一次，不补历史日期；每个任务每天最多一次定时执行，手动点击不限制每日次数。已有运行中的作品时等待完成后再启动。同任务参考创作会跳过以前成功执行用过的资料，无新资料时记录原因；手动创作可以明确复用旧资料。

定时产生的作品仍可编辑、检查、导出。公众号文章默认留在本地；可在任务的“生成后，交付到哪里？”中选择“保存到公众号草稿箱”或“自动发布到公众号”。视频和图片任务仍保留在本地。停止服务会中断运行，重启后保留内容并显示恢复入口。

### 公众号连接与自动发布

在文章任务中展开“连接 / 管理公众号”，选择账号主体和接入方式。个人、企业 / 组织均可配置，已有连接保留官方 API 方式，不自动改动任务的交付方式和定时计划。

- **官方 API**：填写连接名称、AppID、AppSecret，保存并检测。连接在各任务间共用，AppSecret 在 Windows 下通过 DPAPI 加密保存，不进入 API 返回值、执行快照和导出文件。首次检测需要在公众号后台把运行本服务的公网 IP 加入 IP 白名单。企业认证不等于所有接口已授权，以实际检测为准。
- **个人公众号**：[微信官方说明](https://developers.weixin.qq.com/doc/service/guide/product/publish.html)自 2025 年 7 月起收回个人主体等账号的发布接口权限，添加白名单不能解除限制。可使用“扫码接入”，无需 AppID / AppSecret；登录后选择“保存到公众号草稿箱”，定时采集、文章生成、上传配图与封面、声明 AI 生成、保存草稿会自动执行。网页署名最多 8 字。自动保存后重新打开验证内容，执行记录显示微信草稿编号；由用户在微信后台预览、发表。**个人号无人值守公开发表尚未验证，当前不开放**。
- **扫码登录**：本机独立浏览器加载微信官方二维码；管理员在微信中选择公众号、确认登录。中间验证页面显示在弹窗中，可点击继续。登录完成后读取后台可见的 AppID 并绑定身份，重新扫码不能换成其他公众号。会话与草稿后台地址在 Windows 下 DPAPI 加密保存，不复用个人浏览器资料、不返回 Cookie 或带令牌的地址。可取消、重新扫码、清除本机登录；清除后自动存草稿需重新登录。微信要求验证或登录过期时保留本地文章，登录后可重试；进入编辑器后结果不明则停止重提，避免自动保存产生重复草稿。
- **生成待发布稿件**：个人和企业均可选，不要求扫码或 API 权限。定时生成结果提供固定版本排版正文和图文 ZIP，状态显示“待你发布”，由用户在微信后台粘贴、上传图片、预览并发布。复制或下载不会标记为发布成功。

选择发布公众号、默认封面和可选署名，选择交付方式，然后切换自动执行并保存任务。定时执行及“立即自动执行一次”将先按配置采集、生成正文，再上传封面和文内图片、创建微信草稿；选择自动发布时继续提交发布并每约 30 秒查询最终状态，成功后在执行记录显示原文链接。手动草稿和 AI 分步辅助不会触发交付。文章检查存在错误时保留在本地，修订并检查后可重试。正常完成无需逐篇确认；本地电脑和服务需持续运行。

这里使用官方 `stable_token`、`material/add_material`、`media/uploadimg`、`draft/add`、`freepublish/submit`、`freepublish/get` 接口。权限检测仅获取草稿数量及已发布列表，不创建草稿或发布文章。**发布不等于向粉丝群发**，当前不调用群发接口。标题最长 32 字、摘要最长 120 字，系统生成时会加入这些要求；超限会显示原因，不擅自截断正文。

每次交付保存独立的账号、文章版本、微信草稿与发布编号。提交结果不明确时停止重新提交并提示到公众号后台核对；取得发布编号后只查询结果，不重发。已发布后的本地编辑不会修改微信上的文章。微信拒绝发布或采集验证失败均会保留执行记录，无法承诺所有情况下完全无人处理。

## 我的模型

在**我的模型**保存多个命名连接，各任务选择自己的模型。原连接保留为默认模型。

支持 OpenAI 兼容的 Responses / Chat Completions 协议，输出格式可选 JSON Schema、JSON 模式或普通文本 JSON。填写基础 API 地址、模型 ID 和密钥；完整 `/responses`、`/chat/completions` 地址会规范化。HTTPS 服务和本机 HTTP 模型可用，不支持所有厂商私有协议。

测试连接只使用当前表单发起一次小型请求，不自动保存，可能产生服务商费用。新模型请求使用最新保存的连接；运行记录只保存连接 ID，不保存密钥。

密钥存放在 `data/model-config.json`、`data/model-library.json`。Windows 使用当前用户的 DPAPI 加密，其他系统使用当前用户文件权限；API 响应不包含密钥。留空保留旧密钥，勾选清除可删除；更换 API 地址必须重新填写密钥。Windows 密文不能直接迁到另一用户或机器。`.env` 中的 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL` 是默认连接的兼容配置。

## 素材与采集

**素材库**保存公共采集来源、已收集资料和上传的图片/视频。每个任务还可单独配置来源，不影响其他任务。

- **联网查找**：可选“微信公众号文章”或“公开网页与资讯”。公众号搜索使用搜狗微信公开索引，最多读取 3 页 / 30 条候选，按账号、标题、日期去重，保留账号、发布日期和摘要；正文跳转需要验证时仅保存摘要，不绕过验证。普通网页通过 Bing 资讯 RSS 收集，不可用时回退网页搜索。关键词留空时使用任务所选模型提取；持续创作按本次具体主题搜索。手动词建议如“平遥古城 游览攻略”，避免只填宽泛地名。
- **相关性与时效**：先核验时间，再用所选模型按具体写作要求作语义筛选（支持 AI / 人工智能等同义表达），不按搜索顺序直接采用。支持近 7/30/90/365 天或不限时间；以本次采集开始时间为截止点，限期搜索排除过期、未来、无日期条目，取得全文后再次核对日期。搜狗当前带时间参数会跳回首页，因此由平台执行时间筛选，不保证搜索候选都是近期文章。显示实际关键词、冻结的时间范围、检索页数、候选/排除/保留数量，以及被排除文章的日期、链接和原因；每次最多采集 8 篇，额外合格结果单独计数。搜索结果为空时不回填旧资料，筛选失败也不采用未经确认的结果。未配置模型时手动关键词可做字面匹配，正式 AI 创作仍需模型。
- **爆款边界**：公开公众号搜索不提供可核验阅读量，显示“阅读量未提供 / 热度未核验”，不是爆款排行榜。可到新榜等榜单自行选文，再导入原文链接或正文。自动按阅读量、点赞量筛选需要另行接入有权限的数据服务；当前未实现付费榜单 API，不把普通搜索结果伪装成高阅读文章。
- **指定网址**：支持公开文章（包括可访问的公众号文章）、网页列表、RSS/Atom；任务最多 10 个网址，每个来源选取最多 8 条线索。
- **采集清单**：执行记录列出所有采集文章的标题、摘要和原文链接，标明哪些实际用于本次创作。新执行保存完整清单快照；旧记录缺少快照时展示任务中可找到的同来源资料，并明确标注。
- **已有资料**：可选择最多 20 条，每次使用最多 5 条。
- **指定文章导入**：读取单篇文章；无法自动取得正文时，用户可粘贴有权访问的正文并保留原文链接。
- **个人笔记**：作为本次作品的参考快照，不依赖外部网页。
- 上传素材记录使用权说明和署名，可在文章、视频、图片中复用。

网页采集先读取正文和结构化内容，必要时使用 Playwright 与本机 Edge/Chrome 加载动态页面；可在 `.env` 设置 `STUDIO_BROWSER_PATH`，其他环境运行 `python -m playwright install chromium`。采集浏览器使用独立会话，不读取日常浏览器的 Cookie。登录、验证码、付费和复杂页面可能无法自动读取；不会把验证页保存成正文。

采集校验公网地址、重定向和 DNS，限制下载大小及时间；浏览器请求经临时代理阻止本机/内网访问。保存链接去重，来源删除或停用不删除历史资料。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
npm run build
npm run test:ui
```

浏览器测试需先启动服务，默认使用本机 Edge，可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 覆盖。交互测试模拟模型和业务 API，不改变用户作品或消耗真实模型额度。

后端覆盖真实 FFmpeg 合成、PNG 生成、导出、来源采集、模型密钥保护、任务隔离、执行快照、定时幂等、失败恢复、版本冲突和历史迁移。浏览器覆盖新建三类任务、配置保存、模型库、文章完整流程、图片/视频编辑、未保存保护和移动端布局。

服务仅绑定本机，使用 SQLite 与单个 Uvicorn worker；当前不支持多用户协作或直接公网部署。依赖记录在 `requirements.lock.txt` 与 `package-lock.json`。
