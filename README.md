# 知序 · 科学漫游编辑部

鹈鹕骑行风格的本地科学自媒体工作台。当前成片方式：**相关图片／视频 + 1–2 句简短标题，固定 10 秒，无配音、无原声、无逐句字幕**。

## 启动

项目位于 `D:\github\science-studio`。Windows PowerShell 中运行：

```powershell
cd D:\github\science-studio
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 <http://127.0.0.1:8765>。停止服务使用 `powershell -ExecutionPolicy Bypass -File .\stop.ps1`。后端改动后重启；前端改动后运行 `npm run build`。开发模式使用 `start.ps1 -Dev`，前端端口 5173。

要求：Python 3.11+、Node.js 20.19+、中文字体。无需语音引擎；FFmpeg 由 `imageio-ffmpeg` 提供。已在当前 Windows 机器验证。

## 制作流程

1. 首次打开没有选题，也没有启用的采集源。在“每日选题 → 采集数据配置”输入网址，点击“保存并采集”，网络资料会显示在下方；配置 AI 后可推荐最多 5 个适合十秒视觉表达的选题。
2. 写 1–2 句中文短标题，每句最多 28 字，保留原文依据并做事实复核。
3. 整理 1–5 个相关画面，平均分配 10 秒。实时资料尝试使用来源页关联图片；没有可用图片时暂停，提示补充素材。
4. 图片图集、视频片段或混合素材合成竖屏 MP4。短标题放在画面顶部，不叠加品牌水印或底部署名，素材署名保留在交付包的发布说明和出处清单中。所有输入音轨移除，图片和视频保持完整比例。视频支持指定截取起点，片段不足时定格最后一帧补足。
5. 自动检查 10 秒时长、无音轨、可解码性和黑帧；人工核对标题、素材、署名，通过后下载交付包。

## 素材和编辑

“成片审核 → 编辑文案与画面”可修改短标题、增删与调整画面顺序、选择素材和视频截取起点。

- 图片：JPG、PNG、WebP，最多 20 MB、2400 万像素。
- 视频：MP4、MOV、WebM，最多 100 MB、最长 10 分钟、画面尺寸不超过 4K。
- 上传时填写使用权来源和署名。素材可预览；存储路径相对数据目录，便于迁移。
- 保存生成新版本，旧审核失效；重新制作后再审核。
- 不自动下载任意网站的视频。来源页图片与选题是否相关、具体图片署名和使用条件仍需人工核对。

## 成片与交付

交付包包含 MP4、JPG 封面、文案 JSON、发布说明 TXT、出处与素材清单 JSON、质检 JSON；不生成配音或字幕文件。

升级会保留已有采集资料、来源配置、旧成片和审核记录。旧内置示例不再显示在选题页或首页，也不能新建示例制作任务；已有示例任务仍可播放、编辑。旧长视频保存编辑并重新制作时使用新十秒格式。

## 页面配置资料源和 AI

采集配置位于“每日选题”，AI 模型和每日计划位于“每日路线”。保存立即生效，无需重启。

**采集数据配置**：直接填写任意领域的公开 HTTP/HTTPS 网址，点击“保存并采集”即可执行，无需 AI 密钥或科学方向。名称默认使用网站域名；“更多选项”可选择自动识别、RSS/Atom、网页正文/列表或浏览器加载。最多保存 20 个自定义来源，另可自行勾选 NASA、ESA、CERN 和 Nature 常用网址（默认均未启用）。可先预览，也可只保存配置；预览不会写入选题库。采集结果逐个显示成功或失败，部分失败不影响已采集的资料。再次执行按链接去重。删除/停用来源保留已有选题；停用所有来源会关闭每日计划。选题展示、AI 推荐和调度均不再按旧科学方向过滤。

采集配置使用 `PUT /api/source-settings` 单独保存，不覆盖模型连接或其他创作偏好；随后 `POST /api/collect` 执行采集。启动不会导入示例选题，`GET /api/topics` 仅返回网络资料。

网页采集先提取正文、标题、结构化文章、图片地址和链接，正文不足或收到验证页时尝试浏览器加载；也可手动选择浏览器模式处理动态内容。公众号正文支持 `#js_content` 和延迟加载图片。指定文章不会被网站的 RSS 广告链接替换成整站订阅源。列表最多读取 8 个同站子页面，订阅源最多处理 20 条。完整快照会用于后续制作，避免制作时重复访问导致失败。页面上可展开查看已采集正文和链接。

浏览器加载使用 Playwright 与本机 Edge/Chrome；可通过 `.env` 的 `STUDIO_BROWSER_PATH` 指定路径，其他环境运行 `python -m playwright install chromium`。它使用独立会话，不读取日常浏览器的 Cookie 或登录资料。浏览器请求通过本机临时代理校验公网 IP 并固定连接地址，保留 TLS 验证；限制请求数量、时间和大小，不访问本机/内网，也不自动完成验证码。

“浏览器能打开”与“采集能读取”可能因会话状态不同而有差异。仍收到验证页、登录页或已删除提示时，会准确报告且不把错误页录入选题库。可点击“打开原文”，在有访问权限的浏览器中复制正文，通过“导入网页正文”保存链接与内容；导入内容明确标记为手动导入，仍需核验并补充图片/视频素材。这不保证所有网站都能自动抓取，登录、验证码、付费内容和部分复杂动态应用仍有访问限制。

**AI 模型连接**：填写连接名称、API Base URL、模型 ID 和 API Key。支持 OpenAI 官方或兼容中转站，选择 Responses 或 Chat Completions 协议，以及 JSON Schema、JSON 模式或普通文本 JSON。程序始终验证返回结构；兼容模式不会绕过事实依据和文案校验。地址填写到 `/v1` 等服务商给出的基础路径即可，完整 `/responses`、`/chat/completions` 地址也会规范化。HTTPS 服务和本机 HTTP 模型可用。

“测试连接”会按当前填写内容实际请求一次小型 JSON 输出，不保存配置；记录在当日调用统计中，可能产生服务商费用。不自动重试、不自动切换协议。保存后新请求使用页面配置。中转站必须支持所选的 OpenAI 兼容协议，并能输出有效 JSON；不支持所有厂商的私有 API 协议。

API Key 保存于 `data/model-config.json`，Windows 使用当前用户的 DPAPI 加密；其他系统使用仅当前用户可读的文件权限。GET API、任务快照和页面均不返回密钥。修改时留空保留旧密钥，选择“清除”可删除；更换 API 地址必须重新填写 Key，避免误送旧凭据。Windows 密文不能直接迁到其他用户/机器。`.env` 中的 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL` 仍作为首次页面保存前的兼容配置，页面配置优先。

协议实现参考：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)、[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

未配置密钥也能保存采集配置、预览网址和采集资料。AI 推荐及制作网络选题需要先配置模型。本次采集流程测试使用隔离数据和模拟网络/模型响应，不消耗真实模型额度。

每日定时默认关闭；开启后按北京时间执行，需要服务保持运行。每日计划执行一次，自动创建一条未制作选题；手动制作任务和 AI 请求不设每日次数上限，统计仅用于查看。过时启动补跑当天一次，不补跑历史日期。不自动发布。

## 项目结构

```text
src/                    React 工作台、SVG 动画、文案与素材编辑
backend/app.py          API、版本审核、上传与下载
backend/models.py       十秒文案与设置约束
backend/short_render.py 图集/视频、短标题、FFmpeg 合成与质检
backend/media.py        图片导入、图片/视频上传、素材准备
backend/worker.py       持久任务与制作队列
backend/ai.py           选题、短标题、事实复核
backend/sources.py      内置/自定义 RSS、网页采集与预览
backend/web_extract.py  通用正文、公众号、结构化文章、图片及链接提取
backend/browser_fetch.py 浏览器动态加载与公网代理
backend/network.py      公网地址检查、重定向与有限下载
backend/model_config.py 模型连接持久化与密钥保护
backend/seed.py         旧示例测试夹具（启动不加载）
backend/scheduler.py    每日调度
backend/db.py           SQLite 数据
tests/                 API、真实合成、浏览器验证
data/                  数据库、素材与成片（不入版本库）
```

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
npm run build
npm run test:ui
```

后端测试包括空库启动/重启、采集配置即时生效、去重、失败处理、历史数据兼容，以及图集、视频和混合画面的真实 FFmpeg 合成，检查固定 10 秒、音轨移除、视频素材上传及交付文件。浏览器测试需先启动服务；视频播放用例需要已有十秒成片且至少两个画面。使用本机 Edge，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 覆盖。

配置测试覆盖密钥不回显、持久化、即时生效、保留/清除、切换地址、两种协议与三种输出格式、采集预览、去重、启停和公网边界。通用采集测试包含非科学内容、微信验证页回退、JavaScript 真实加载、私网子请求阻断、正文快照复用和手动导入。浏览器配置测试使用模拟接口，不改用户设置或消耗真实模型额度。

依赖版本记录在 `requirements.lock.txt` 与 `package-lock.json`。服务仅绑定本机，采用 SQLite 和单 worker；不支持多用户和直接公网部署。模型复核不能替代科学内容及素材的人工检查。
